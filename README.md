# Rami Taleb – Web Developer Portfolio

**Live Site**: [ramitaleb.netlify.app](https://ramitaleb.netlify.app/)

A modern and responsive personal portfolio website to showcase my work, skills, and experience as a front-end and full-stack web developer. Built to highlight projects, provide contact information, and demonstrate design and development capabilities.

## ✨ Features

- 🔥 Clean and minimal UI
- 📱 Fully responsive on all devices
- 🧠 Showcases projects with GitHub/demo links
- 💼 About Me & Skills sections
- 📬 Contact form for inquiries
- 🌐 Deployed on Netlify

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Reactjs)**
- **Font Awesome** for icons
- **Netlify** for hosting
